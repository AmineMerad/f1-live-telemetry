# Data rights checklist (recheck before implementation, payment, publication)

- [ ] OpenF1: field coverage, session availability, rate limits, auth,
      subscription terms, sampling (∼3.7 Hz) vs. delivery cadence vs. latency,
      live delay (∼3 s), CC BY-NC-SA non-commercial constraints, attribution
- [ ] FastF1: exploration-only vs. production use; data rights vs. software licence
- [ ] Outcome-label policy defined (retirements, DSQ, unclassified, post-race changes)
- [ ] No raw dataset / branding publication until terms reviewed
